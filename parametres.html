Paramètres

Plan d'entraînement (CSV)

Deux formats de CSV sont acceptés :

— Format détaillé (séparateur point-virgule) : Semaine, Date (JJ/MM/AAAA), Jour, Bloc / Phase, Type de séance, Distance, D+, D-, Durée totale, FC échauffement, FC corps de séance, FC retour au calme, FC moyenne globale, Intensité (RPE), Objectif de la séance. C'est le format à privilégier — la date complète évite d'avoir à préciser l'année.

— Format simple (séparateur virgule) : Semaine, Bloc, Jour (ex. "Ven 07/08", sans année), Type de séance, Distance (km), D+ (m), Intensité (RPE), Notes. Dans ce cas, renseigne l'année de la saison ci-dessous.

Détail du plan importé

Regroupé par semaine — clique sur une semaine pour la déplier. La semaine en cours est ouverte automatiquement.

Clé API Claude (pour le retour qualitatif IA — optionnel)

Votre clé reste uniquement sur cet ordinateur (stockage local du navigateur) et n'est envoyée qu'à l'API Anthropic, jamais ailleurs. Sans clé, le dashboard fonctionne normalement — seul le retour IA par séance (page Historique) ne sera pas disponible.

Gestion des données

Séances, plan, courses, profil, équipements et clé API sont stockés uniquement dans ce navigateur (localStorage). Rien n'est envoyé sur un serveur, hormis les appels volontaires à l'API Claude. Pour retrouver tes données sur un autre appareil (ex. téléphone), exporte le JSON depuis cet appareil-ci puis importe-le là-bas.

Synchronisation entre appareils (Supabase)

Optionnel. Une fois configuré et connecté, tes données se synchronisent automatiquement entre tous tes appareils (PC, téléphone...) dès qu'ils ont accès à internet. Sans configuration, le dashboard continue de fonctionner normalement en local uniquement.
