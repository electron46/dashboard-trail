Thème :

Plan d'entraînement (CSV)

Colonnes attendues : Semaine, Bloc, Jour (ex. "Ven 07/08"), Type de séance, Distance (km), D+ (m), Intensité (RPE), Notes. L'année est supposée être 2026 — modifiable dans assets/app.js (constante PLAN_YEAR) si le plan change de saison.

Clé API Claude (pour le retour qualitatif IA — optionnel)

Votre clé reste uniquement sur cet ordinateur (stockage local du navigateur) et n'est envoyée qu'à l'API Anthropic, jamais ailleurs. Sans clé, le dashboard fonctionne normalement — seul le retour IA par séance (page Historique) ne sera pas disponible.

Gestion des données

Séances, plan, courses, profil, équipements et clé API sont stockés uniquement dans ce navigateur (localStorage). Rien n'est envoyé sur un serveur, hormis les appels volontaires à l'API Claude. Pour retrouver tes données sur un autre appareil (ex. téléphone), exporte le JSON depuis cet appareil-ci puis importe-le là-bas.

Dashboard local — aucune donnée envoyée ailleurs que l'API Anthropic (si clé renseignée ci-dessus).
