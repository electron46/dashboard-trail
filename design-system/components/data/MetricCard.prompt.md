Tuile de métrique isolée — la brique de base du dashboard (distance, D+, FC, allure). Toujours label en mono majuscule + valeur en mono. `na` affiche "Non disponible" sans jamais inventer une valeur.

```jsx
<MetricCard label="Distance" value="12,40" unit=" km" />
<MetricCard label="FC max" na />
```
