Span inline pour une valeur chiffrée au milieu de texte courant (ex. dans une phrase, une cellule de tableau, une carte de course). C'est la brique la plus élémentaire de la signature visuelle — jamais de couleur, seulement le changement de police qui signale "ceci est une donnée".

```jsx
<p>Sortie terrain, <DataValue>D+ 800 m</DataValue></p>
<DataValue size="lg" emphasis>5'10/km</DataValue>
```
