Bouton carré pour une icône seule (fermer un panneau, action secondaire de table). Passe l'icône en `children` — un SVG line-art (Lucide/Feather) 18–20px de préférence.

```jsx
<IconButton aria-label="Fermer"><XIcon size={18} /></IconButton>
<IconButton active aria-label="Filtres actifs"><FilterIcon size={18} /></IconButton>
```
