# UI Kit — Dashboard ELEV

Recréation stylée du dashboard de suivi trail/running fourni en référence (`uploads/dashboard-trail.html`, conservé tel quel — non restylé, gardé comme spec fonctionnelle uniquement).

Ce kit reprend la même structure fonctionnelle — échéances, import de séances `.fit`, plan d'entraînement, progression, historique filtrable, détail de séance, retour IA, export/reset — avec l'identité ELEV : anthracite/blanc cassé, IBM Plex Sans pour l'UI, IBM Plex Mono pour toute valeur chiffrée, pas de couleur d'accent.

Composé à partir de `components/core`, `components/forms`, `components/data`, `components/feedback`, `components/navigation`. `data.jsx` contient les données de démonstration (échéances, séances factices).
