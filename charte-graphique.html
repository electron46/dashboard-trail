Logo

Concept

  • Symbole simple et abstrait : ligne (courbe d'allure / trace GPS simplifiée), point de repère, ou monogramme "E" basé sur ELEV.
  • Pas d'illustration détaillée.
  • 3 déclinaisons à prévoir : logo complet (texte + symbole), symbole seul (icône/avatar), version monochrome.

Design tokens

Couleurs

--color-primary:   #2B2B2B;  /* anthracite — texte, fonds sombres, logo */
--color-secondary: #F2F1EE;  /* blanc cassé — fonds clairs, rapports */
--color-accent:    #FF6B35;  /* à valider — données chiffrées uniquement */
Règle stricte : jamais plus d'une variable accent utilisée simultanément dans une même vue.
Typographie

Font stack

--font-ui:   'Inter', 'IBM Plex Sans', -apple-system, sans-serif;
--font-data: 'IBM Plex Mono', 'JetBrains Mono', ui-monospace, monospace;

--font-ui pour titres et texte courant. --font-data réservée aux valeurs chiffrées (distance, allure, D+, temps) — jamais au texte courant.

Composants

Convention d'affichage des données

Toute métrique (distance, allure, D+, temps, date) s'affiche en --font-data, idéalement colorée en --color-accent quand elle est mise en avant (KPI, chiffre clé).

<span class="metric">12,4 km</span>

.metric {
  font-family: var(--font-data);
  color: var(--color-accent);
}
Contexte technique

Fichiers sources

  • Logo en SVG comme source unique → export PNG / favicon depuis ce fichier.
  • Pas de dépendance à une banque d'images ou de filtre CSS type "vintage/glossy".
  • Iconographie : privilégier des sets line-art (ex. Lucide, Feather) plutôt que des icônes pleines/glossy.
